# Передача файлов по TCP и UDP

Клиент и сервер на Python для передачи файлов по двум протоколам. Проект выполнен как тестовое задание.

**Стек:** Python · socket · TCP · UDP · Bash  
**Исходный код:** [file-transfer-udp-tcp](https://github.com/ST3PAN0V/file-transfer-udp-tcp)

## Что реализовано

- [TCP-версия](https://github.com/ST3PAN0V/file-transfer-udp-tcp/tree/tcp): передача файла через установленное соединение.
- [UDP-версия](https://github.com/ST3PAN0V/file-transfer-udp-tcp/tree/udp): запрос клиента и отправка файла датаграммами.
- Bash-проверки с запуском клиентского и серверного процессов; TCP-проверка сравнивает полученный файл с исходным.

Для запуска нужна ветка `tcp` или `udp`: в `main` находятся обзор и пустые заготовки исходников. Каждый сервер рассчитан на одну передачу; UDP-реализация не содержит подтверждений доставки и повторной отправки.

[Настройка, запуск и ограничения](https://github.com/ST3PAN0V/file-transfer-udp-tcp#readme)
