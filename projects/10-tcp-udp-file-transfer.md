# Передача файлов по TCP и UDP

Клиент-серверное приложение на Python для передачи файлов по двум сетевым протоколам. Реализации TCP и UDP находятся в отдельных ветках.

| О проекте | Описание |
| --- | --- |
| **Исходный код** | [file-transfer-udp-tcp](https://github.com/ST3PAN0V/file-transfer-udp-tcp) |
| **Контекст** | Тестовое задание |
| **Стек** | Python · socket · TCP · UDP · Bash |

## Что реализовано

| Ветка | Реализация |
| --- | --- |
| [tcp](https://github.com/ST3PAN0V/file-transfer-udp-tcp/tree/tcp) | Сервер передаёт содержимое файла подключённому клиенту через TCP-сокет. |
| [udp](https://github.com/ST3PAN0V/file-transfer-udp-tcp/tree/udp) | Сервер получает запрос клиента и отправляет содержимое файла UDP-датаграммами. |

В обеих ветках есть отдельные клиент и сервер, а также Bash-скрипты проверки. TCP-скрипт создаёт случайный файл, запускает программы и сравнивает полученное содержимое с исходным. Ветка `main` содержит обзор проекта и пустые заготовки исходников; для запуска нужна ветка `tcp` или `udp`.

## Инженерные решения

- Работа с соединениями и обмен данными через Python-сокеты.
- Практическое сравнение семантики доставки TCP и UDP.
- Координация клиентского и серверного процессов из Bash.
- Проверка содержимого файла отдельно от сообщений программы об успешном завершении.

## Границы реализации

Это небольшие реализации для тестового задания. В UDP-версии нет подтверждений доставки и повторной отправки пакетов. Каждый сервер рассчитан на одну передачу за запуск.
