# Игровой сервер на C++

HTTP-бэкенд онлайн-игры: игровые сессии, асинхронная обработка запросов, сохранение состояния и таблица результатов в PostgreSQL.

| О проекте | Описание |
| --- | --- |
| **Исходный код** | [backend_server](https://github.com/ST3PAN0V/backend_server) |
| **Контекст** | Учебный проект курса по бэкенд-разработке на C++ |
| **Стек** | C++20 · Boost.Asio · PostgreSQL · libpqxx · CMake · Conan · Docker · Catch2 |

## Задача

Предоставить игровым клиентам API для входа в сессию, получения состояния и отправки команд движения. Сервер должен обновлять игровую модель, идентифицировать участников по токенам и сохранять результаты завершивших игру пользователей.

## Что реализовано

- **JSON API:** список карт, подключение к игре, игроки, состояние сессии, действия и таблица результатов.
- **Асинхронная обработка:** Boost.Asio и несколько рабочих потоков.
- **Игровые сессии:** токены игроков, обновление модели и выполнение команд.
- **Сохранение состояния:** сериализация и восстановление игры.
- **Таблица результатов:** записи завершивших игру участников в PostgreSQL, сортировка и постраничная выдача.

## Инженерные решения

Проект объединяет HTTP-слой, прикладную логику, игровую модель и доступ к базе данных. Отдельные тесты проверяют поведение модели, обработку столкновений, генерацию объектов и сериализацию.

Для сборки и запуска подготовлены конфигурации CMake и Conan, Dockerfile и документация.
