# 🎮 Игровой сервер на C++

HTTP-бэкенд онлайн-игры с сессиями, сохранением состояния и таблицей результатов. Учебный проект курса по бэкенд-разработке на C++.

**Стек:** C++20 · Boost.Asio · PostgreSQL · libpqxx · CMake · Conan · Docker  
**Исходный код:** [backend_server](https://github.com/ST3PAN0V/backend_server)

## Что реализовано

- JSON API для получения карт, подключения к игре, действий игроков и просмотра состояния.
- Асинхронная обработка HTTP-запросов на нескольких рабочих потоках Boost.Asio.
- Игровые сессии, токены участников и обновление модели по игровым тактам.
- Сериализация состояния и восстановление игры из сохранённых данных.
- Таблица результатов в PostgreSQL с сортировкой и пагинацией.

## Ключевые решения

HTTP-слой, игровая модель и доступ к базе разделены по ответственности: правила игры можно развивать отдельно от обработки запросов и хранения результатов. Модульные тесты охватывают модель, столкновения, генерацию объектов и сериализацию. В репозитории есть конфигурации CMake и Conan, Dockerfile и инструкции запуска.

## Результат

Клиент может получить карту, подключиться к сессии, управлять персонажем и посмотреть таблицу рекордов. Проект объединяет сетевое взаимодействие, состояние приложения и базу данных в одной учебной серверной системе, включая сохранение игры между запусками.
