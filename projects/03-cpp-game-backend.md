# Игровой сервер на C++

HTTP-бэкенд онлайн-игры с сессиями, сохранением состояния и таблицей результатов. Учебный проект курса по бэкенд-разработке на C++.

**Стек:** C++20 · Boost.Asio · PostgreSQL · libpqxx · CMake · Conan · Docker  
**Исходный код:** [backend_server](https://github.com/ST3PAN0V/backend_server)

## Что реализовано

- JSON API: карты, подключение к игре, состояние, действия игроков и результаты.
- Асинхронная обработка запросов на нескольких рабочих потоках.
- Игровые сессии, токены участников и обновление модели.
- Сериализация состояния и восстановление игры; хранение результатов в PostgreSQL с сортировкой и пагинацией.

## Ключевые решения

HTTP-слой, игровая модель и доступ к базе данных разделены по ответственности. Тесты проверяют модель, столкновения, генерацию объектов и сериализацию. Подготовлены сборка через CMake и Conan, Dockerfile и описание API.
