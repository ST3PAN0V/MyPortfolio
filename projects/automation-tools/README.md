# Automation Tools

Smaller projects for reducing repetitive work through Telegram interfaces, document processing, and command-line reports.

## Event Registration Bot

**Source code:** Private  
**Stack:** Python · TeleBot · SQLite

A Telegram bot for event registration, with step-by-step data collection, participation options, and administrative handlers. It stores registration records in SQLite and includes Telegram payment workflows.

**Engineering focus:** conversational forms, persistent records, user/admin flows, and payment-event handling.

## DOCX Automation Tool

**Source code:** Private  
**Stack:** Python · Tkinter · python-docx · PyInstaller

A desktop application for batch editing Word documents and generating files from templates. It supports replacements in paragraphs and tables, and creates document sets from supplied values.

**Engineering focus:** turning repetitive document operations into a reusable GUI workflow.

## Workload Imbalance Report

**Source code:** [school2024-test-task6](https://github.com/ST3PAN0V/school2024-test-task6)  
**Context:** CROC Summer IT School selection task  
**Stack:** C++17 · STL · CMake

A command-line utility that processes weekly time entries, compares recorded hours with a target, and generates a sorted report of deviations greater than 10%. Underwork and overtime are listed separately.

**Engineering focus:** input parsing, aggregation, sorting, and report generation.
