# Игры на C++

Учебные проекты для практики игровой логики, обработки ввода, отрисовки и сборки C++-приложений.

## TerminalAdventure

Терминальное приключение с противниками, предметами, несколькими этажами и растущей сложностью. Библиотека ncurses отвечает за интерфейс и обработку клавиатуры.

**Стек:** C++17 · ncurses · CMake · Docker  
**Что отрабатывалось:** структура приложения, игровая логика и воспроизводимая сборка.

[Код, сборка и управление](https://github.com/ST3PAN0V/TerminalAdventure)

## Game

Ранняя незавершённая графическая игра с управлением с клавиатуры и загрузкой уровней из текстовых карт.

**Стек:** C++ · OpenGL · GLUT · Make · Linux  
**Что отрабатывалось:** отрисовка, обработка ввода и разделение приложения и игровой логики.

[Код и описание](https://github.com/ST3PAN0V/Game)
