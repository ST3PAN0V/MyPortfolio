# Игры на C++

Ранние проекты для практики игровой логики, пользовательского ввода, терминального и графического интерфейса, а также сборки C++-приложений.

## TerminalAdventure

**Исходный код:** [TerminalAdventure](https://github.com/ST3PAN0V/TerminalAdventure)  
**Стек:** C++17 · ncurses · CMake · Docker

Терминальная игра с противниками, предметами, несколькими этажами и растущей сложностью. Библиотека ncurses отвечает за отображение игрового мира и обработку клавиатуры.

**Что отрабатывалось:** структура приложения, интерактивная игровая логика, терминальный интерфейс и воспроизводимая сборка.

[Сборка и управление](https://github.com/ST3PAN0V/TerminalAdventure#readme)

## Game

**Исходный код:** [Game](https://github.com/ST3PAN0V/Game)  
**Статус:** ранний незавершённый учебный проект  
**Стек:** C++ · OpenGL · GLUT · Make · Linux

Графическая игра с управлением с клавиатуры и загрузкой уровней из текстовых карт. Репозиторий сохранён как один из первых проектов, вместе с исходными ограничениями реализации.

**Что отрабатывалось:** отрисовка, обработка ввода и разделение основного приложения и игровой логики.

[Описание и запуск](https://github.com/ST3PAN0V/Game#readme)
