# 🤖 Бот регистрации на мероприятия

Заказная разработка Telegram-бота для организации, проводящей мероприятия. Бот помогает участникам ознакомиться с событием, зарегистрироваться и выбрать категорию участия, а организаторам — управлять базой пользователей через административную панель.

**Стек:** Python · pyTelegramBotAPI · SQLite · Telegram Payments  
**Тип проекта:** коммерческий заказ  
**Исходный код:** закрытый

## Что реализовано

- Информационное меню мероприятия и связь с поддержкой.
- Пошаговая регистрация участников с вводом ФИО и телефона.
- Выбор категории участия и отображение информации о билетах.
- Интеграция с Telegram Payments: создание платёжных счетов и обработка подтверждения успешной оплаты.
- Сохранение Telegram ID, username, контактных данных и категории участия в SQLite.
- Административная панель с ограничением доступа по списку администраторов.
- Экспорт базы пользователей, статистика по категориям, изменение категории и очистка пользовательских данных.
- Ручное добавление записей в базу.

## Технические решения

- Разделение пользовательских и административных обработчиков.
- Отдельный модуль доступа к SQLite на базе стандартного `sqlite3`.
- Отдельные соединения с базой, потоковая блокировка, WAL и busy timeout.
- Логирование событий бота и операций с базой данных.

## Результат

Организаторы получили единый Telegram-интерфейс для сбора регистраций и администрирования участников мероприятия. Пользовательские данные и выбранные категории участия сохраняются в базе и доступны для дальнейшей работы через административные инструменты.
