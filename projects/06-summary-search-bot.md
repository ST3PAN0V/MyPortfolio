# SummarySearchBot

**Telegram-ассистент для анализа переписки за выбранный период и подготовки сводок со ссылками на исходные сообщения.**

| О проекте | Описание |
| :--- | :--- |
| **Исходный код** | Закрытый |
| **Направление** | Сбор данных · Обработка текста · Интеграция с языковой моделью |
| **Стек** | Python, asyncio, Kurigram, OpenRouter |

## Задача

Собрать нужную информацию из нескольких каналов и чатов, когда она распределена по большой истории сообщений. Результат должен соответствовать запросу пользователя и сохранять связь с первоисточниками.

## Что реализовано

- Сбор сообщений из нескольких выбранных Telegram-источников.
- Ограничение выборки заданным временным интервалом.
- Разбиение большого объёма текста на части для обработки.
- Подготовка сводок языковой моделью с учётом запроса пользователя.
- Ссылки на исходные сообщения в результате.

## Инженерные решения

Проект объединяет асинхронное получение данных и обработку длинных текстов. Отдельное внимание уделено прослеживаемости результата: ссылки позволяют вернуться от сводки к сообщениям, на которых она основана.
