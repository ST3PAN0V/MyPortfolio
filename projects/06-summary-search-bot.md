# 📝 SummarySearchBot

Telegram-ассистент с локальной LLM, который превращает переписку за выбранный период в сводку со ссылками на исходные сообщения.

**Стек:** Python · asyncio · Kurigram · локальная LLM  
**Исходный код:** закрытый

## Что реализовано

- Собирает сообщения из нескольких выбранных Telegram-каналов и чатов.
- Ограничивает выборку заданным временным интервалом.
- Разбивает длинную историю переписки на части для обработки.
- Готовит сводку с помощью локальной языковой модели с учётом запроса пользователя.
- Сохраняет ссылки на исходные сообщения, чтобы выводы можно было проверить в контексте.

## Ключевые решения

Асинхронное получение данных объединено с обработкой длинных историй сообщений. Разбиение текста помогает работать с материалом, который нельзя передать модели целиком. Ссылки сохраняют связь между кратким ответом и конкретными сообщениями, на которых он основан.

## Результат

Пользователь получает сводку по заданной теме и периоду, а для проверки деталей может открыть первоисточники. Ассистент собирает информацию из нескольких обсуждений в один обзор, сокращая объём переписки, которую нужно просматривать вручную.
