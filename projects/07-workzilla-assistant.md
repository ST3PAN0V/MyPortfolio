# 🛠️ Workzilla Bot

Сервис с локальной LLM, который отслеживает заказы на Workzilla, выделяет подходящие задачи и отправляет их в Telegram.

**Стек:** Python · httpx · Workzilla API · Telegram Bot API · локальная LLM  
**Открытая версия:** [workzilla_bot](https://github.com/ST3PAN0V/workzilla_bot)

## Что реализовано

- Получает заказы через Workzilla API.
- Классифицирует описания задач с помощью локальной языковой модели.
- Отправляет подходящие предложения в Telegram.
- Готовит черновик отклика по запросу пользователя.

## Ключевые решения

Клиенты внешних API, анализ задач, генерация откликов и управление процессом разделены по модулям. Это позволяет менять получение заказов, обработку текста или доставку уведомлений отдельно. В открытой версии есть конфигурация пакета, тесты и инструкции запуска.

## Результат

Подходящие заказы поступают в Telegram, а по запросу пользователя сервис готовит черновик отклика. Получение предложений, их анализ и подготовка ответа объединены в один сценарий работы с фриланс-заказами.

> В открытом репозитории [LLM-клиент](https://github.com/ST3PAN0V/workzilla_bot/blob/main/shared_llm/client.py) настроен на YandexGPT.
