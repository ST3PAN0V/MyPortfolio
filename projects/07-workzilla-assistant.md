# Ассистент для Workzilla

Python-сервис, который отслеживает заказы на фриланс-площадке, анализирует их с помощью YandexGPT и отправляет подходящие предложения в Telegram.

| О проекте | Описание |
| --- | --- |
| **Исходный код** | [workzilla_bot](https://github.com/ST3PAN0V/workzilla_bot) |
| **Направление** | Интеграция API · Классификация текста · Уведомления |
| **Стек** | Python · httpx · Workzilla API · YandexGPT · Telegram Bot API |

## Задача

Сократить ручной просмотр входящих заказов: объединить получение задач, анализ описаний и отправку уведомлений. По запросу пользователя сервис также готовит черновик отклика.

## Что реализовано

- Получение заказов через клиент Workzilla API.
- Классификация описания задачи с помощью языковой модели.
- Отправка подходящих предложений в Telegram.
- Генерация черновика ответа по запросу пользователя.
- Разделение доступа к API, анализа, уведомлений и управления процессом по отдельным модулям.

## Инженерные решения

Каждая внешняя интеграция отвечает за свою часть процесса. Это позволяет рассматривать получение заказов, анализ и доставку уведомлений отдельно. В репозитории есть конфигурация пакета, тесты и инструкции по запуску сервиса.
