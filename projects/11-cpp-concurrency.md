# Асинхронность и многопоточность в C++

Модель обработки ресторанных заказов для изучения асинхронных операций, таймеров и совместной работы нескольких потоков в Boost.Asio.

## Что реализовано

Асинхронные таймеры моделируют этапы приготовления заказа. Несколько рабочих потоков выполняют обработчики общего `io_context`: пока один заказ ожидает таймер, потоки могут обрабатывать другие события.

Добавление результатов в общую коллекцию последовательно выполняется через strand. Логи с временными отметками показывают ход выполнения, а итоговые проверки `assert` контролируют состояние готовых заказов.

## Инженерные решения

- Разделение ожидания события и блокирующей работы в потоке.
- Запуск цикла событий Asio на нескольких потоках `std::jthread`.
- Последовательное изменение общей коллекции результатов.
- Синхронизированный вывод логов для наблюдения за параллельным выполнением.
