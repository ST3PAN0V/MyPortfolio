# Асинхронность и многопоточность в C++

Учебная модель обработки ресторанных заказов на Boost.Asio: таймеры, несколько рабочих потоков и общий набор результатов.

**Стек:** C++20 · Boost.Asio · CMake · Conan  
**Исходный код:** [Multi_Threading_practice](https://github.com/ST3PAN0V/Multi_Threading_practice)

## Что реализовано

- Асинхронные таймеры для моделирования этапов приготовления.
- Общий `io_context`, обработчики которого выполняют несколько потоков `std::jthread`.
- Последовательное добавление результатов в коллекцию через strand.
- Синхронизированные логи с временными отметками и итоговые проверки состояния заказов.

Проект показывает совместную работу цикла событий и потоков. Область действия синхронизации и ограничения реализации описаны в README.
