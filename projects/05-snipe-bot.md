# 🎯 SnipeBot

Асинхронный инструмент для мониторинга перепродажи Telegram-подарков и автоматизации покупок с проверкой актуальной цены. Объединяет наблюдение за предложениями, выполнение операций и инструменты для проверки соединения и разбора активности.

**Стек:** Python · asyncio · Telethon · aiohttp · Click  
**Исходный код:** закрытый

## Что реализовано

- Мониторинг предложений через Telegram API с использованием Telethon.
- Повторная проверка цены перед отправкой платежа и отмена покупки при её изменении.
- Фоновые уведомления о результатах операций и отчёты об активности.
- CLI для запуска мониторинга, подготовки метаданных и диагностики соединения.
- Измерение длительности проверок соединения и запросов на покупку.

## Ключевые решения

Мониторинг, покупки и уведомления запускаются как асинхронные задачи. Доступ к Telegram, метаданные и отчётность выделены в отдельные модули. Если соединение недоступно, перед операцией предусмотрено восстановление подключения. Проверка цены связывает решение о покупке с состоянием предложения перед платежом.

## Результат

Из командной строки можно запустить мониторинг и покупки с проверкой цены, проверить подключение и просмотреть отчёты. Уведомления и измерения длительности запросов помогают разбирать результаты работы инструмента.
