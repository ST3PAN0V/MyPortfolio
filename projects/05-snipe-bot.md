# SnipeBot

**Асинхронный инструмент для мониторинга перепродажи Telegram-подарков и автоматизации покупок.**

| О проекте | Описание |
| :--- | :--- |
| **Исходный код** | Закрытый |
| **Направление** | Telegram API · Асинхронные сценарии · Командная строка |
| **Стек** | Python, asyncio, Telethon, aiohttp, Click, uvloop, cryptg |

## Задача

Координировать запросы к Telegram API, отслеживать изменения объявлений и выполнять покупки с проверкой условий. Мониторинг, обработка покупки и уведомления должны работать согласованно; для сопровождения нужны диагностика соединения и отчёты об активности.

## Что реализовано

- Асинхронный мониторинг через Telegram API и Telethon.
- Проверка актуальной цены перед отправкой платежа.
- Фоновые уведомления о результатах операций.
- Интерфейс командной строки на Click: мониторинг, инициализация метаданных, диагностика соединения и отчёты.
- Измерение длительности проверок подключения и запросов на покупку.

## Организация приложения

Команды CLI запускают нужный сценарий. Мониторинг и обработка покупок выполняются как асинхронные задачи. Доступ к Telegram, работа с метаданными, уведомления и отчёты выделены в отдельные модули.

## Инженерные решения

- Согласованная работа конкурентных API-запросов и фоновых задач.
- Восстановление соединения с Telegram перед операцией, если оно недоступно.
- Отмена покупки при изменении цены.
- Диагностика и служебные команды рядом с основным торговым сценарием.
