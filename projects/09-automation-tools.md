# Инструменты автоматизации

Небольшие приложения для подготовки документов и обработки отчётов.

## Обработка документов DOCX

Настольное приложение для пакетной замены текста в абзацах и таблицах Word и создания наборов документов по шаблонам.

**Стек:** Python · Tkinter · python-docx · PyInstaller  
**Исходный код:** закрытый

## Отчёт о рабочем времени

Консольная утилита суммирует время за неделю и формирует отсортированный отчёт об отклонениях от нормы более чем на 10%. Недоработки и переработки выводятся отдельно.

**Стек:** C++17 · STL · CMake  
**Контекст:** отборочное задание Летней ИТ-школы КРОК

[Код, формат данных и запуск](https://github.com/ST3PAN0V/school2024-test-task6)
