# Инструменты автоматизации

Небольшие приложения для регистрации участников, подготовки документов и обработки отчётов.

## Бот регистрации на мероприятия

**Исходный код:** закрытый  
**Стек:** Python · TeleBot · SQLite

Telegram-бот с пошаговым сбором данных, выбором варианта участия и административными обработчиками. Записи о регистрации сохраняются в SQLite; предусмотрена обработка платежей через Telegram.

**Инженерные задачи:** диалоговые формы, хранение записей, сценарии пользователя и администратора, обработка платёжных событий.

## Обработка документов DOCX

**Исходный код:** закрытый  
**Стек:** Python · Tkinter · python-docx · PyInstaller

Настольное приложение для пакетного редактирования документов Word и создания файлов по шаблонам. Поддерживает замены в абзацах и таблицах, а также формирование наборов документов по заданным значениям.

**Инженерные задачи:** перенос повторяющихся операций с документами в удобный графический интерфейс.

## Отчёт об отклонениях рабочего времени

**Исходный код:** [school2024-test-task6](https://github.com/ST3PAN0V/school2024-test-task6)  
**Контекст:** отборочное задание Летней ИТ-школы КРОК  
**Стек:** C++17 · STL · CMake

Консольная утилита обрабатывает записи за рабочую неделю, сравнивает суммарное время с нормой и формирует отсортированный отчёт об отклонениях более чем на 10%. Недоработки и переработки выводятся отдельно.

**Инженерные задачи:** разбор входных данных, агрегация, сортировка и формирование отчёта.

[Формат данных, сборка и запуск](https://github.com/ST3PAN0V/school2024-test-task6#readme)
