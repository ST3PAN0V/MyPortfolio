# Диалоговый ИИ-бот

**Telegram-ассистент с контекстом переписки, лимитами использования и оплатой пакетов ответов через Telegram Stars.**

| О проекте | Описание |
| :--- | :--- |
| **Исходный код** | Закрытый |
| **Направление** | Хранение состояния · Обработка платежей · Конкурентные запросы |
| **Стек** | Python, httpx, SQLite, Telegram Bot API, интеграция с языковой моделью |

## Задача

Сохранять контекст диалога между запросами, учитывать доступные пользователю ответы и обрабатывать сообщения из разных чатов. Покупка пакета ответов должна согласованно обновлять платёжное состояние сервиса.

## Что реализовано

- Работа в личных сообщениях и группах с сохранением контекста и учётом лимитов.
- Хранение состояния приложения и платёжных записей в SQLite.
- Оплата пакетов ответов через Telegram Stars.
- Транзакционные операции со счетами и проверка уже существующих активных счетов.
- Управление конкурентной обработкой запросов с последовательным выполнением внутри каждого чата.

## Инженерные решения

В одном сервисе объединены контекст диалога, учёт использования и платежи. Последовательная обработка внутри чата сохраняет порядок работы с его состоянием, а управление конкурентностью позволяет координировать запросы из разных чатов.

Тесты охватывают поведение бота, хранилище, конфигурацию и журналирование.
