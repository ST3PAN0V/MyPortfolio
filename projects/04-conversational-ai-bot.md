# 💬 Диалоговый ИИ-бот

Telegram-ассистент для личных сообщений и групп с контекстом переписки, лимитами использования и оплатой пакетов ответов через Telegram Stars. Проект охватывает задачи вокруг обращения к модели: историю разговора, учёт доступных ответов и платежи.

**Стек:** Python · httpx · SQLite · Telegram Bot API · LLM  
**Исходный код:** закрытый

## Что реализовано

- Диалоги в личных сообщениях и группах с сохранением контекста разговора.
- Учёт квот и доступного количества ответов.
- Покупка пакетов через Telegram Stars и хранение платёжных записей.
- Транзакционные операции со счетами и проверка наличия активных счетов.
- Последовательная обработка сообщений одного чата при конкурентной работе с разными чатами.

## Ключевые решения

Контекст, квоты и платежи связаны через состояние в SQLite. Порядок обработки внутри чата помогает согласованно обновлять его данные, пока другие чаты продолжают обрабатываться независимо. Тесты охватывают поведение бота, хранилище, конфигурацию и логирование.

## Результат

Пользователь может продолжать разговор с учётом истории, расходовать доступные ответы и покупать дополнительные пакеты в Telegram. Работа с языковой моделью и управление доступом к ней объединены в одном интерфейсе.
