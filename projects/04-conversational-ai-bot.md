# Диалоговый ИИ-бот

Telegram-ассистент с контекстом переписки, лимитами использования и оплатой пакетов ответов через Telegram Stars.

**Стек:** Python · httpx · SQLite · Telegram Bot API · LLM  
**Исходный код:** закрытый

## Что реализовано

- Диалоги в личных сообщениях и группах с сохранением контекста.
- Учёт доступных ответов, оплата пакетов и хранение платёжных записей.
- Транзакционные операции со счетами и проверка активных счетов.
- Последовательная обработка сообщений внутри чата при конкурентной работе с разными чатами.

## Ключевые решения

Контекст, квоты и платежи связаны через состояние в SQLite. Порядок обработки внутри чата помогает согласованно обновлять его данные. Тесты охватывают поведение бота, хранилище и конфигурацию.
